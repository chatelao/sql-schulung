# 200-Lektionen-Zeitplan & Pacing-Modelle

Jede Lektion dauert **45 Minuten**, was insgesamt **150 Zeitstunden** über **10 Phasen** und **6 identische Checkpoints (`CP-0`–`CP-5`)** ergibt.

---

## Wähle deinen Lernrhythmus

### Track 1: Intensiv-Vollzeit-Bootcamp (5 Wochen)
- **Takt**: 8 Lektionen/Tag (6 Zeitstunden/Tag), 5 Tage/Woche = **40 Lektionen/Woche**.
- **Woche 1 (`L001–L040`)**: Phase 1 + Phase 2 (bis `DEFINE`/`VERIFY`)
- **Woche 2 (`L041–L080`)**: `CP-1`, Phase 3 (Functions), Phase 4 (Grouping)
- **Woche 3 (`L081–L120`)**: `CP-2`, Phase 5 (Joins), Phase 6 (Subqueries & `SET` Operators)
- **Woche 4 (`L121–L160`)**: `CP-3`, Phase 7 (DML/TCL), Phase 8 (DDL/Constraints/Views/Indexes)
- **Woche 5 (`L161–L200`)**: `CP-4`, Phase 9 (Data Dictionary/Time Zones/DCL), Phase 10 (Mock Exams & `CP-5`)

### Track 2: Berufsbegleitender Abend-/Wochenendkurs (20 Wochen)
- **Takt**: 10 Lektionen/Woche (z. B. Di & Do abends × 3 Lektionen + Samstag × 4 Lektionen).
- Ideal für Berufstätige, die sich in Richtung Data, QA oder Oracle-Entwicklung weiterbilden.

### Track 3: Schul-/Studienjahr im eigenen Tempo (34 Wochen)
- **Takt**: 6 Lektionen/Woche (4,5 Stunden/Woche).
- Lässt bewusst Raum für wöchentliche Spaced-Repetition-Flashcards auf GitHub Pages.

## Checkpoint-Zeitplan über die 200 Lektionen

| Checkpoint | Lektionen | Zeitpunkt | Was passiert |
| :---: | :---: | :--- | :--- |
| **CP-0** | `L001–L002` | Start von Phase 1 | Ehrliche Zero-Knowledge-Baseline (ohne vorher zu lernen). |
| **CP-1** | `L041–L042` | Ende von Phase 2 | Misst Fortschritt in Domains 1–2 + Confidence Calibration. |
| **CP-2** | `L081–L082` | Ende von Phase 4 | Misst den großen Punktesprung aus Domain 3 (25 % Exam Weight). |
| **CP-3** | `L121–L122` | Ende von Phase 6 | Meilenstein: erstmaliges Überschreiten der **65-%**-Prüfungshürde. |
| **CP-4** | `L161–L162` | Ende von Phase 8 | Vollständiger Query- + DDL/DML-Check (Ziel: **75 %+**). |
| **CP-5** | `L199–L200` | Ende von Phase 10 | Abschluss-Benchmark (**≥ 85 %**) + vollständiger Answer Key freigeschaltet! |
